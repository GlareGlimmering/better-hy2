## v1.1.0-rc.7 候选版登录时序验收

在非特权本机隔离实例测试已校验 SHA256 的 RC.6 发布面板及 RC.7 候选面板。使用临时管理员和普通代理账号，每隔约 1.12 秒交替提交不存在的用户名和有效管理员的错误密码，各 24 次。两类响应体完全相同，均为 HTTP 200、应用码 50000。

| 版本 | 不存在的用户名中位数（ms） | 有效管理员密码错误中位数（ms） | 配对差中位数（ms） | 管理员组更慢的样本对数 |
| --- | ---: | ---: | ---: | ---: |
| RC.6 | 1.12 | 23.97 | +22.84 | 24/24 |
| RC.7 候选版 | 33.35 | 32.51 | −1.15 | 8/24 |

候选版拒绝伪造转发头的第 6、7 次请求（HTTP 429），可信反代登录返回 HTTP 200、应用码 20000。普通代理账号、改密前旧令牌、篡改令牌、签名有效的过期令牌和畸形令牌均返回 HTTP 200、应用码 50000。无令牌返回 HTTP 200、应用码 50401。公网链路未纳入本轮复测。
