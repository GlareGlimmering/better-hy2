# Better HY2 预发布验收记录

实现侧 Codex 负责写代码、修复缺陷并运行自动化检查。操作者与审阅助手负责审阅、提出功能需求及验收，由操作者在两边转接指令和结果。仓库交付与发布规则见 [AGENTS.md](../AGENTS.md)。

## v1.1.0-rc.1 账户带宽控制

- 面板 `v1.1.0-rc.1` 对应标签提交 `43b15a5dd0289ef901356a5f9863c078cd33a80c`。
- 实测 HY2 内核版本为 `v2.13.0-hui.5-dev`，版本输出中的提交为 `54a51aaac00fa53a1378e20f207d54f7ac8d2b7e`。面板和 HY2 内核分别版本化。
- 操作者报告使用 iPhone 小火箭和 Speedtest.net，在单客户端上分别设置 4、6、7 Mbps，三个配置的下载限速均生效。该轮仅测试下载。

| 待补人工验收 | 记录内容 |
| --- | --- |
| 上传限速 | 设置不同的上传和下载值，记录双向测速结果。 |
| 同账号多连接 | 用两个独立 HY2 连接并行下载，记录各自吞吐与合计值。 |
| 动态调速 | 调整下载限速时保持原连接，分别记录原连接与新连接的行为，对照实现侧给出的生效条件与时间。 |
| 流量配额 | 用独立测试账号耗尽配额，记录新连接是否被拒绝、已有连接如何处理及结算时间。 |
| 重启与流量结算 | 在测试环境对比重启前后的累计流量与可用配额，检查是否漏计或重复结算。 |
| 离线恢复 | 在测试环境演练回滚，记录面板、HY2 内核、SQLite、Xray 和服务状态的恢复结果。 |

仓库配置了 [systemd 离线恢复工作流](../.github/workflows/systemd-recovery.yml)。验收时分别记录 CI 运行链接及对应提交、人工操作步骤及实测结果。复测记录应包含面板版本、内核版本、客户端、设置值与观测值。账号、订阅地址、凭据、生产日志与配置仅保存在各自的私有环境。
